# Security Overview

This repository contains public project information and approved screenshots only. The website's source code and private project files are kept separately.

myY1themestudio keeps theme work local:

- local browser processing for theme files and images;
- no account database or remote theme-upload service;
- checks for unsafe archive paths before imported files enter the browser workspace;
- explicit reporting of missing or unreadable assets rather than silent replacement;
- preservation of original imported files while edits occur in a browser working copy; and
- explicit downloadable backups in addition to local autosave.

Public showcase files are reviewed for credentials, private workstation paths, unapproved source material, and unexpected binary changes before publication.

Please do not publish sensitive security details in a public discussion. Contact mp3li privately through the Patreon link in the README when private disclosure is necessary.
