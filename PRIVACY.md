# Privacy Overview

myY1themestudio is designed so theme work stays with the person creating it.

- Theme ZIPs, folders, images, fonts, configuration data, image processing, and generated exports remain in the browser on the user's device.
- The studio does not require an account and does not provide remote theme storage or a theme-upload service.
- Autosave and preferences use local browser storage. Clearing site data can remove that locally saved information, so downloadable editable backups are available.
- A theme leaves the browser only when the user explicitly downloads or saves it.
- Links to external websites are governed by those websites' own privacy practices.

When the website is publicly hosted, the hosting provider may process ordinary request information needed to deliver the site, such as IP address, browser details, requested files, and timestamps. This does not include the contents of themes being edited in the studio.

I'll update this page if the way myY1themestudio handles user data changes.
